# 집결 연결 대상 집수리 지원사업 조사 (2026년 기준)

- 조사일: 2026년 10월 1일
- 조사 방법: 서울시 공식 누리집, 서울시 보도자료, 언론 보도 검색
- 주의: 사업 조건과 금액은 해마다 바뀐다. 앱에 넣기 전에 공고 원문으로 다시 확인하고, 사업마다 기준일을 기록한다.

신뢰도 표시
- 상: 서울시 또는 기관 공식 누리집이나 보도자료에서 확인
- 중: 주요 언론 보도로 확인
- 하: 민간 정리 사이트에서만 확인. 공식 확인 필요

## 4. 매칭 규칙에 넣을 조건 정리

| 조건 | 쓰는 사업 | 집결에서 얻는 방법 |
|---|---|---|
| 기준 중위소득 구간 (48%, 60%, 100%) | 수선유지급여, 희망의 집수리, 안심 집수리 보조 | 사용자 질문 (정확한 소득 대신 5절의 단계별 질문으로) |
| 주거급여 수급 여부 | 수선유지급여(대상), 희망의 집수리(제외) | 사용자 질문 |
| 자가 / 임차 | 수선유지급여(자가만), 희망의 집수리(둘 다) | 사용자 질문 |
| 주택 연식 (10년, 20년 이상) | 안심 집수리 보조, 융자 | 건축물대장 사용승인일 |
| 저층주택, 반지하, 옥탑방 | 안심 집수리 보조 | 건축물대장 + 사용자 질문 |
| 통합돌봄 대상 | 안심 집수리 보조, 희망의 집수리 우선 | 사용자 질문 |
| 신청 기간 | 모든 사업 | 사업 데이터에 접수 기간을 넣고, 기간이 지나면 "다음 모집 안내"로 표시 |

## 5. 소득 질문 설계와 2026년 기준 중위소득

### 5.1 왜 정확한 소득을 묻지 않나

지원사업의 소득 기준은 월급이 아니라 소득인정액(실제 소득 + 재산의 소득환산액)이다. 주민이 스스로 계산할 수 없고, 앱이 계산하려면 재산 정보까지 받아야 해서 개인정보 부담이 크다. 그래서 집결은 수급 여부와 대략적인 소득 구간만 묻고, 결과는 "해당될 수 있어요"로 안내하며, 최종 판단은 상담에 맡긴다.

### 5.2 질문 순서

| 순서 | 질문 | 판정 | 다음 |
|---|---|---|---|
| 1 | "주거급여를 받고 계세요?" | 예: 기준 중위소득 48% 이하 | 자가면 수선유지급여, 희망의 집수리는 제외. 2, 3번 건너뜀 |
| 2 | "기초생활수급자나 차상위계층이세요?" | 예: 대략 50% 이하 | 희망의 집수리, 에너지효율개선 가능. 3번 건너뜀 |
| 3 | 가구원 수 + "한 달 가구 소득은 대략 어느 쪽인가요?" | 60% 이하 / 60~100% / 100% 초과 | 구간에 맞는 사업 표시 |
| 항상 | "잘 모르겠어요" | 판정 보류 | 사업은 보여 주고, 카드에 "소득과 재산 기준은 상담에서 확인" |

### 5.3 2026년 기준 중위소득과 구간 금액 (월, 원)

| 가구원 수 | 기준 중위소득 100% | 60% | 48% |
|---|---|---|---|
| 1인 | 2,564,238 | 1,538,543 | 1,230,834 |
| 2인 | 4,199,292 | 2,519,575 | 2,015,660 |
| 3인 | 5,359,036 | 3,215,422 | 2,572,337 |
| 4인 | 6,494,738 | 3,896,843 | 3,117,474 |
| 5인 | 7,556,719 | 4,534,031 | 3,627,225 |
| 6인 | 8,555,952 | 5,133,571 | 4,106,857 |

- 100% 금액은 보건복지부 고시(2026년도 기준 중위소득). 60%와 48%는 100% 금액에 비율을 곱해 원 단위에서 반올림한 값이다.
- 검산: 1인 48%(1,230,834원)는 보건복지부가 발표한 2026년 1인 가구 주거급여 선정기준(123만 834원)과 같다.
- 앱 버튼에는 만 원 단위로 보여 준다. 예: 1인 가구 "154만 원보다 적어요 / 154만~256만 원 / 256만 원보다 많아요 / 잘 모르겠어요"
- 기준 중위소득은 매년 8월 전후에 다음 해 금액이 고시되므로 연 1회 갱신한다.
