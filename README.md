## 왜 만드나요

월계1동은 고령 인구와 오래된 주택의 비율이 높은 동네입니다. 이런 동네에서는 누수, 곰팡이, 창문 틈새처럼 집에 문제가 생겨도 다음과 같은 이유로 지원을 받지 못하는 경우가 많습니다.

- **어떤 지원사업이 있는지 모릅니다.** 집수리 지원사업은 서울시, 자치구, 기관별로 흩어져 있고 공고마다 이름과 조건이 다릅니다.
- **내가 해당되는지 판단하기 어렵습니다.** 소득, 연령, 주택 연식, 자가 또는 임차 여부 같은 조건을 공고문을 읽으며 직접 확인해야 합니다.
- **검색 방식이 맞지 않습니다.** 기존 서비스는 정책 이름이나 분야로 검색해야 합니다. 하지만 주민이 아는 것은 정책 이름이 아니라 "욕실 천장에서 물이 샌다"는 사실입니다.
- **디지털 이용이 어렵습니다.** 고령 주민일수록 여러 누리집을 오가며 정보를 모으기 어렵습니다.

## 어떻게 해결하나요

집결은 정책 이름 대신 **집의 문제**에서 시작합니다.

```
사진 촬영 → 문제 유형 분류 → 조건 확인 → 지원사업 연결 → 상담 준비 카드 → 상담·신청 연계
```

1. **사진 촬영:** 수리가 필요한 곳을 찍습니다.
2. **문제 유형 분류:** AI가 사진을 보고 누수, 곰팡이, 창문 틈새 같은 문제 유형을 1차로 분류합니다. 사진이 어려우면 그림 목록에서 직접 고를 수도 있습니다.
3. **조건 확인:** 연령, 주택 유형, 자가 또는 임차 여부 같은 간단한 질문에 답합니다. 주택 연식과 사용승인일은 건축물대장 공공데이터로 자동 조회합니다.
4. **지원사업 연결:** 문제 유형과 조건에 맞는 서울시·노원구 집수리 지원사업을 보여 줍니다.
5. **상담 준비 카드:** 확인된 조건, 아직 확인이 필요한 항목, 준비할 서류를 한 장으로 정리해 줍니다.
6. **상담·신청 연계:** 카드를 들고 주민센터나 관련 기관 상담으로 바로 이어갈 수 있게 안내합니다.

## 무엇이 다른가요

| | 기존 방식 | 집결 |
|---|---|---|
| 출발점 | 정책 이름, 분야 검색 (복지로, 집수리닷컴 등) 또는 행정 데이터 기반 맞춤 안내 (복지멤버십 등) | 주민이 직접 보는 **집의 실제 상태** |
| 조건 확인 | 공고문을 읽고 직접 판단 | 간단한 질문 + 건축물대장 자동 조회 |
| 결과 | 정보 제공에서 끝남 | 상담 준비 카드로 실제 상담과 신청까지 연결 |

행정 데이터 기반 안내는 소득이나 가구 정보는 알지만, 지금 그 집의 지붕이 새는지는 알 수 없습니다. 집결은 이 빈틈을 주민의 사진과 간단한 답변으로 채우려고 합니다.

## 안전하게 동작하도록

- **분류가 어려우면 사람에게 연결합니다.** AI가 확신하지 못하거나 해당 사업이 없으면 월계1동 행정복지센터 상담으로 바로 안내합니다.
- **AI는 판단을 대신하지 않습니다.** AI는 문제 유형을 고르는 일만 하고, 지원사업 연결은 정리된 사업 데이터와 규칙으로 합니다. 최종 자격 판단은 상담 기관에서 이루어집니다.
- **조회가 안 되면 직접 입력합니다.** 건축물대장 조회에 실패하면 수동 입력으로 전환합니다.
- **임차 가구를 고려합니다.** 임차 가구에는 집주인 동의가 필요하다는 점을 미리 안내합니다.
- **다른 지역 주민도 안내합니다.** 다른 지역 주소를 입력하면 안내 문구를 보여 주고 복지로로 연결합니다.

## 쉬운 화면

고령 주민이 혼자 쓸 수 있도록 큰 글씨, 쉬운 말, 한 화면에 한 가지 일만 하는 단계형 화면을 기본으로 설계합니다.

## 개인정보 원칙

- 사진의 위치 정보(EXIF)는 지우고 처리합니다.
- 사진 원본은 저장하지 않는 것을 원칙으로 합니다.
- 외부 AI 서비스로 사진이 전송되는 경우 화면에 미리 알립니다.
